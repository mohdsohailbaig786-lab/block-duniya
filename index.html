Game ke bare mein

Block Duniya — apni chhoti duniya mein banao aur khojo. Tamam block art aur naqsh code se banay gaye hain.

Baen joystick se chalo, daen drag se camera ghumao aur upar/neechay dekho. Jump se chhalang, Todo se toro, Rakh se block rakho. Neechay samaan chuno. Camera se Upar / Aankh. Survival mein Banao aur Khao istemal karo. Desktop: WASD, Space, Q / E; Esc se mouse azad.
